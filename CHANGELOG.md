# Changelog

## 0.1.3 — голоса iOS 18+ (2026-11-16)

- С iOS 18 Safari отдаёт сайтам только простые синтезаторы: Eloquence (Flo, Reed, Sandy…), MacinTalk (Albert, Fred…) и шуточные голоса. Samantha и скачанные улучшенные голоса недоступны. Теперь Eloquence ранжируются выше MacinTalk, поэтому по умолчанию звучит Flo, а не Albert.
- В выборе голоса появился вариант «Системный голос iPhone»: голос не задаётся, iOS выбирает сам.
- Подсказка «скачай голос» заменена честным объяснением ограничения.

## 0.1.2 — нормальный голос по умолчанию и выбор голоса (2026-11-16)

- Голоса ранжируются по качеству: премиум → улучшенный → обычный → роботизированный. «Шуточные» голоса Apple (Bad News, Bells, Zarvox…) убраны совсем. Раньше голоса сортировались по алфавиту, и на iPhone первым попадался Albert или Bad News.
- Выбор голоса с прослушиванием, выбор запоминается. Подсказка, как скачать улучшенный голос в настройках iPhone.
- Тесты на выбор голоса.

## 0.1.1 — исправление звука на iPhone (2026-11-16)

- Озвучка запускается синхронно прямо в обработчике нажатия: раньше код сначала ждал список голосов (до 2 с), и iOS Safari молча блокировал звук.
- Если голоса ещё не загрузились — говорим голосом по умолчанию с `lang=en-US`, а не молчим.
- `cancel()` вызывается только если что-то уже звучит (в Safari `cancel()` сразу перед `speak()` иногда «съедает» фразу).
- Если звук не начался за 4 секунды — показываем ошибку вместо вечного «Звучит…».
- Блок «Не слышно? Диагностика»: число голосов, выбранный голос, режим запуска, версия iOS, журнал событий синтеза, кнопки «Простой сигнал» и «Голос по умолчанию».

## 0.1.0 — Этап 1: каркас и деплой (2026-11-16)

- Vite + React 19 + TypeScript (strict) + Tailwind CSS 4.
- PWA: манифест, иконки (в т.ч. `apple-touch-icon` 180×180 и maskable), свой Service Worker (прекэш всего приложения, офлайн, обработчики `push` и `notificationclick`, плашка «Доступно обновление»).
- Экран «Сегодня»: кольцо минут, стрик/заморозки/повторения (пока нули), проверка звука (en-US), подсказка по установке на iPhone, индикатор офлайна.
- Учебные сутки по Москве с границей в 04:00 (`src/lib/time.ts`) + тесты.
- `navigator.storage.persist()` при запуске.
- GitHub Actions `deploy.yml`: проверка секретов → валидация контента → тесты → сборка → GitHub Pages.
- Pre-commit хук против утечки секретов и личных данных.
