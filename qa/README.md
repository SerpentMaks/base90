# Проверки Base90

17 ноября 2026. Локальная production-сборка, Chromium мобильного профиля, ширина 390 px. Измерение выполнено после окончания генерации, на полной сборке: 4 905 озвученных текстов, 4 958 AAC-файлов (42,84 МиБ). Service Worker включает 5 030 ресурсов для офлайна.

Lighthouse 13.6.0: Performance **97**, Accessibility **100**, Best Practices **100**, LCP **2,7 с**. Исходный отчёт: `lighthouse.json`. Это лабораторное измерение, не обещание одинаковой скорости на всех устройствах. Реальная установка на iPhone отдельно не проверена.

Браузерные проверки проверяют полный путь через интерфейс: онбординг, маршруты на мобильной ширине, десять заданий первой недели и запись FSRS, продолжение слова после перезагрузки, принятие опечатки, синхронизацию двух независимых профилей через тестовый контракт GitHub Gist, файловый экспорт/импорт, личное слово из субтитров. Отдельно проверяются офлайн-загрузка и ответ 206 на запрос 32 байтов аудиофайла.

Серверный Web Push на реальный iPhone и обмен Gist с его браузером требуют личной подписки и токена владельца. Mock Gist проверяет контракт и слияние, но не заменяет эти проверки.

Перечень ручных проверок и настройка уведомлений — в README.md. Все 14 браузерных сценариев прошли на полной сборке. Итоговые результаты и объём аудио — в FINAL_REPORT.md.
