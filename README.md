# Base90

Английский для русскоговорящего новичка: 90 учебных дней, короткие занятия, аудио и интервальные повторения. Сайт: [serpentmaks.github.io/base90](https://serpentmaks.github.io/base90/).

В курсе 1300 слов из NGSL-Spoken/NGSL, 200 разговорных фраз, 13 недель грамматики с 130 упражнениями, минимальные пары и связная речь, диктант, запись голоса, 45 историй и 70 диалогов. У каждого текста есть русский перевод; у историй и диалогов — вопросы. Покрытие словаря на точке открытия проверяется в CI и составляет не менее 95%.

## Установка на iPhone

1. Открой сайт в Safari. Нажми «Поделиться» → «На экран Домой».
2. Запусти Base90 с новой иконки. Дождись сообщения «Готово к работе без интернета». Первая загрузка включает записи всего курса и может занять несколько минут; оставь приложение открытым и подключённым к сети.
3. Проверь звук в настройках. Основной голос — записи Heart. Для запасного синтеза и личных слов скачай английский голос в настройках iPhone: «Универсальный доступ» → раздел устной речи → «Голоса» → English.
4. Отключи сеть и проверь занятие. Новые версии устанавливаются по кнопке «Обновить», прогресс сохраняется.

## Как заниматься

Нажми «Начать». В подход входят повторения, новые слова, короткий урок, звуки, диктант и повторение фразы вслух. Сначала пытайся вспомнить ответ, затем проверяй себя. Ошибка возвращает карточку в повторения. Самооценка: «Не получилось / С трудом / Вспомнил». Автоматические задания не ставят оценку Easy.

Начальный план — 20 минут, +10 каждые три засчитанных **учебных** дня, максимум 90 минут. День засчитывается после 80% плана. Считается активное время на учебном экране, пока последнее действие было не более минуты назад. Время в фоне не начисляется. Граница суток — 04:00 по Москве.

Подход можно прервать крестиком и продолжить с той же карточки. При смене учебных суток составляется новый подход из сохранённых карточек; ответы и расписание остаются. Один подход ограничивает исходные повторения 30 карточками и добавляет не больше пяти новых слов. Дневной лимит считается отдельно. При завале повторений новых слов нет, после долгого перерыва нагрузка временно снижается. Серия сохраняется за десять активных минут или выполнение утренних повторений; заморозки начисляются за семь успешных дней, максимум две.

В «Уроках» доступны грамматика, звуки, тексты и отдельная практика. На неделях 8 и 13 есть справочники 30 неправильных и 30 фразовых глаголов. Будущие уроки можно посмотреть заранее. Месячные тесты на днях 28, 56 и 90 сохраняют результаты и не меняют FSRS. После 90 дней повторения продолжаются.

## Прогресс и резервные копии

Данные хранятся в IndexedDB браузера. iOS может очистить данные сайта, поэтому регулярно сохраняй экспорт или подключи синхронизацию.

**Файл:** «Настройки» → «Экспорт прогресса». На другом устройстве — «Импорт копии». Импорт объединяет записи с текущими. Токен GitHub, запись микрофона и исходный файл субтитров в экспорт не входят. Добавленные вручную слова с выбранным контекстом входят.

**GitHub Gist:** создай отдельный classic Personal Access Token только с правом `gist` по ссылке в настройках. Вставь токен; оставь ID пустым для создания секретного Gist. На втором устройстве введи тот же токен и ID. Секретный Gist доступен любому, кто знает его ссылку; токен предоставляет доступ к гистам аккаунта и остаётся только в локальном хранилище устройства.

Синхронизация выполняется при открытии, после подхода, при уходе в фон, после возврата сети и по кнопке. Ошибка сети оставляет локальный прогресс. Карточки, дни, настройки и учебные отметки объединяются по времени изменения, журнал ответов — по ID. Для снимков больше 500 КБ используется gzip. При одновременном редактировании с двух устройств повтори синхронизацию на каждом: Gist не предоставляет полноценную транзакционную базу.

Сброс отключает локальную синхронизацию и очищает прогресс. Удалённая резервная копия сохраняется и вернётся только после повторного подключения или импорта.

## Уведомления: один раз настроить

На iPhone Web Push работает у приложения с иконки «Домой», начиная с iOS 16.4. Разрешение запрашивается только кнопкой «Включить уведомления».

VAPID уже подготовлен для основного репозитория: приватный ключ и контакт находятся в секретах, публичный ключ — в переменной сборки `VITE_VAPID_PUBLIC_KEY`. Они не хранятся в исходниках. Для своего форка создай новую пару и настрой секреты самостоятельно.

Для умных напоминаний:

1. Подключи Gist в приложении.
2. Открой GitHub → репозиторий → Settings → Secrets and variables → Actions. Добавь секреты `GIST_ID` (из приложения) и `GIST_TOKEN` (отдельный токен только с правом gist).
3. В установленном приложении нажми «Включить уведомления». Подписки разных устройств сохраняются отдельно.
4. Проверь локальное уведомление. Затем GitHub → Actions → «Напоминания Base90» → Run workflow → `force: true`. Это проверка настоящего серверного пуша.

Можно установить секреты через CLI: `gh secret set GIST_ID` и `gh secret set GIST_TOKEN`. Команды принимают значение скрытым вводом; не помещай токен в командную строку или файл репозитория.

Без Gist: в раскрываемом разделе ручной настройки скопируй подписку в секрет `PUSH_SUBSCRIPTION`. Тогда напоминания идут в 10:23, 19:23 и 22:23 МСК и не учитывают выполнение плана. Для отключения такого варианта удали секрет подписки или выключи workflow.

С Gist обычные пуши не приходят после минимума, последний — после полного плана. Ночь 23:00–08:00 исключена; максимум три обычных пуша в сутки. Время и пауза на три дня настраиваются в приложении. Расписание GitHub работает с задержками. Ответ 404/410 выключает истёкшую подписку; приложение восстанавливает её при следующем открытии с выданным разрешением.

`keepalive.yml` еженедельно включает workflow через API и при отсутствии коммитов 21 день делает служебный пустой коммит. Это предотвращает отключение расписания после 60 дней отсутствия активности.

## Мост к фильмам

Выбери локальный `.srt` или `.vtt`. Приложение считает покрытие по леммам и показывает частые незнакомые слова. «Знакомым» здесь считается слово с устойчивостью FSRS от семи дней; процент не равен пониманию сюжета.

Слова курса добавляются кнопкой. Для слова вне курса укажи свой перевод. Сохранится выбранная реплика с таймкодом; личные слова используют системный голос, а не записи Heart. Сохранённые элементы попадут в твой экспорт и подключённый Gist, исходный файл никуда не отправляется.

## Разработка и обновление контента

Требуется Node.js 24, npm, git. `gh` нужен для публикации. Основное приложение не загружает учебный контент из внешних API.

```sh
npm ci
npm test
npm run validate
npm run build
npm run preview
```

Превью находится по адресу `http://localhost:4173/base90/`. Для браузерных проверок:

```sh
npx playwright install chromium
npm run test:e2e
```

Загрузка исходников: `bash scripts/fetch-sources.sh`, затем `node scripts/build-order.ts`. Нужны curl и unzip.

Исходные NGSL CSV и выгрузка ManyThings находятся в игнорируемом `scripts/.cache/`. Переводы и ручные примеры — `scripts/data/enrich`, `enrichment.txt`, `own-examples.json`; истории и диалоги — `scripts/data/course`. Готовые JSON и аудио входят в git, CI ничего не генерирует нейросетью.

```sh
npm run content:words
npm run content:course
npm run audio
npm run validate -- --audio
npm test
npm run build
```

Для сверки IPA слов: `node scripts/enrich.mjs` (словарь en_US загружает fetch-sources). Для IPA фраз нужен локальный инструмент `tools/tts`. После него снова собери контент. Генерация записей требует ffmpeg и скачивает Kokoro-82M с Hugging Face при первом запуске. Модель и инструменты генерации не входят в приложение и CI. Имена файлов определяются текстом и голосом; существующие записи переиспользуются.

Отчёты: `content-report.md` — слова и источники примеров; `course-report.md` — точки открытия текстов, покрытие и незнакомые леммы. Первые 120 базовых слов используются как стартовый словарь при автоматическом подборе примеров: из нескольких первых служебных слов невозможно собрать естественные предложения. Некоторые первые примеры подобраны вручную; это оговорённое методическое приближение.

Push в `main` запускает проверку секретов, схем и аудио, тесты, сборку и GitHub Pages. Ни токены, ни подписки, ни адрес контакта VAPID, ни пользовательские файлы субтитров не должны попадать в коммиты.

## Проверка на настоящем iPhone

Автотесты не заменяют эту проверку:

- [ ] Установить через Safari, открыть с иконки; адресной строки нет.
- [ ] Дождаться готовности офлайна, включить авиарежим и пройти несколько заданий со звуком.
- [ ] Проверить клавиатуру, долгое нажатие на динамик и выбранную скорость.
- [ ] Сделать две записи голоса подряд, затем свернуть и вернуть приложение; при отказе микрофона доступно повторение без записи.
- [ ] Прервать подход, закрыть приложение, снова открыть и продолжить с той же карточки.
- [ ] Синхронизировать прогресс с ПК и обратно; отдельно сохранить экспорт.
- [ ] Проверить настоящий пуш из workflow, открытие по тапу и бейдж повторений.
- [ ] Принять обновление и проверить сохранность прогресса.

Источники и лицензии: `CONTENT_LICENSES.md`. Архитектурные решения и ограничения: `DECISIONS.md`.
