# Base90 — английский с нуля за 90 дней

Офлайн-приложение (PWA) для iPhone: слова по частотности, аудио, грамматика, повторения по FSRS.

**Открыть:** https://serpentmaks.github.io/base90/

## Установка на iPhone

1. Открой ссылку выше в **Safari**.
2. Нажми «Поделиться» → «На экран Домой» → «Добавить».
3. Запускай Base90 с иконки: так оно работает без интернета и может присылать напоминания.

## Для разработки

```bash
npm install      # заодно подключит pre-commit хук против утечки секретов
npm run dev      # локальный сервер
npm test         # тесты
npm run build    # сборка в dist/
```

Пуш в `main` автоматически публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
